# University identity

`dongshin-university-symbol.png` is the original Dongshin University symbol
downloaded on 18 November 2026 from the university's official identity page:

- Identity page: https://www.dsu.ac.kr/kr/index.php?pCode=uisymbol
- Original PNG: https://www.dsu.ac.kr/Share/filedown.php?fdir=kr&f=symbol.png&fn=symbol

The PNG is kept unchanged. CSS scales it proportionally for the page header
and sign-in panel; the browser also uses it as the tab icon.
The university retains rights to its identity artwork.
