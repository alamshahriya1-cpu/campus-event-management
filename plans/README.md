# Project plans

The repository root is the project folder. This directory groups the current
requirements, traceability, responsibility assignments and schedule navigation.

| Planning document | Read | Editable source | Purpose |
| --- | --- | --- | --- |
| Software Requirements Specification | [Overview](srs/README.md) · [PDF](srs/SRS.pdf) | [Word](srs/SRS.docx) | Defines the system's requirements and acceptance criteria. |
| Requirements Traceability Matrix | [Overview](rtm/README.md) · [CSV](rtm/RTM.csv) | [Excel](rtm/RTM.xlsx) | Maps requirements to use cases, diagrams, code, tests and evidence. |
| RACI responsibility matrix | [Overview and image](raci/README.md) · [PDF](raci/RACI_Matrix.pdf) | [Excel](raci/RACI_Matrix.xlsx) | Assigns the two team members' functional responsibilities. |
| Project schedule | [Schedule notes](schedule/README.md) · [Gantt](../docs/diagrams/07_project_gantt.png) | [Generator](../docs/diagrams/source/build_diagrams.py) | Shows the original plan alongside recorded progress. |

## Review together

- [System diagrams](../docs/diagrams/README.md) explain the requirements and workflows.
- [Completion report](../docs/review/COMPLETION_REPORT.pdf) explains the completion calculation and evidence limits.
- [Acceptance record](../docs/review/ACCEPTANCE_RECORD.md) lists the checks still requiring evidence.
- [Original baseline](../docs/archive/2026-10-29-baseline/README.md) preserves the earlier submitted documents.

The SRS and RTM retain revision 2.0 and their recorded requirement statuses.
The folder organization does not change requirement IDs, test results or
completion percentages. RACI is an assignment plan, not proof of completed work.
