# Software Requirements Specification

[Read the PDF](SRS.pdf) · [Download the editable Word document](SRS.docx)

Version 1.0, submission date 29 October 2026. This repository copy preserves the latest supplied SRS, including the project Gantt chart. The PDF is a viewing copy of the Word document.

The specification defines 18 functional and 7 non-functional requirements, interfaces, data structures, API endpoints, system models, and acceptance criteria. Additional standalone diagrams are available in the [diagram directory](../diagrams/README.md).
