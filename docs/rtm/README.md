## Updating the matrix

Maintain the Excel workbook as the source and refresh the CSV after changes. Record actual test evidence separately before changing a requirement to Verified. Keep requirement IDs aligned with the [SRS](../srs/SRS.pdf) and [diagram index](../diagrams/README.md).
